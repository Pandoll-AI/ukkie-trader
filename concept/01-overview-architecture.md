## 1. 프로젝트 개요

### 1.1 프로젝트 철학: 왜 오랑우탄인가?

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  오랑우탄 트레이딩 철학                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  🦧 신중함 (Deliberation)                                                   │
│     → 정의 고정 없이 거래 없음. 모호함은 곧 손실.                             │
│                                                                             │
│  🌳 나무 위의 관찰자 (Observer from Above)                                   │
│     → 시장에 뛰어들기 전 레짐을 파악. 급하면 죽는다.                          │
│                                                                             │
│  🍌 기회의 과일 (Selective Picking)                                          │
│     → 모든 과일을 따지 않는다. 최상의 것만.                                   │
│                                                                             │
│  🤝 장기적 관계 (Long-term Memory)                                           │
│     → 오랑우탄은 최대 8년 전 경험도 기억. 시장도 기억한다.                    │
│                                                                             │
│  🔴 빨간 신호 (Red Flag Response)                                            │
│     → 위험 감지 시 즉시 후퇴. 자존심보다 생존.                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 핵심 설계 원칙

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  PRINCIPLE 1: Definition-First Trading                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  "거래 전에 모든 것을 정의하라"                                              │
│                                                                             │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐  │
│  │   Entry     │ → │    Exit     │ → │  Position   │ → │    Risk     │  │
│  │  Condition  │    │  Condition  │    │    Size     │    │   Limits    │  │
│  └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘  │
│                                                                             │
│  정의 완료 전 = 거래 불가                                                    │
│  정의 변경 시 = 새로운 전략으로 취급                                          │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│  PRINCIPLE 2: Multi-Agent Validation Pipeline                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  단일 검증 = 과신의 시작                                                     │
│  다중 관점 검증 = 생존의 조건                                                │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │                                                                      │  │
│  │  Proposer → Freezer → DataQA → Backtest → CostSim → ExecSim        │  │
│  │      │                                         │                     │  │
│  │      │         ↓                               ↓                     │  │
│  │      │    ┌─────────┐                   ┌───────────┐                │  │
│  │      └───→│ RiskSim │←──────────────────│ OvfitAudit│                │  │
│  │           └────┬────┘                   └───────────┘                │  │
│  │                │                                                     │  │
│  │                ↓                                                     │  │
│  │         ┌───────────┐         ┌─────────────────────┐               │  │
│  │         │ PortfoCap │────────→│   ORCHESTRATOR      │               │  │
│  │         └───────────┘         │ (Final Decision)    │               │  │
│  │                               └─────────────────────┘               │  │
│  │                                                                      │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│  PRINCIPLE 3: Regime-Aware Everything                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  시장은 단일 상태가 아니다. 레짐별 전략이 필요하다.                           │
│                                                                             │
│  ┌────────────┬────────────┬────────────┬────────────┐                     │
│  │   NORMAL   │  VOLATILE  │  ILLIQUID  │   EVENT    │                     │
│  ├────────────┼────────────┼────────────┼────────────┤                     │
│  │ Vol < 2σ   │ Vol > 2σ   │ Spread > X │ News/Macro │                     │
│  │ Spread ≤ X │ Spread > X │ Depth < Y  │ Scheduled  │                     │
│  │ Normal Ops │ Risk ↓     │ Size ↓     │ Pause/Exit │                     │
│  └────────────┴────────────┴────────────┴────────────┘                     │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│  PRINCIPLE 4: Progressive Deployment                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  급진적 배포 = 급진적 손실                                                   │
│                                                                             │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐             │
│  │  SHADOW  │ → │  PAPER   │ → │   LIVE   │ → │   PROD   │             │
│  │ (Log)    │    │ (Sim $)  │    │ (Min $)  │    │ (Full)   │             │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘             │
│       ↓              ↓              ↓               ↓                      │
│    2주 관찰       2주 관찰       1개월 관찰     규제/승인 필요               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
