🦧 Ukkie CLI 소개

Ukkie Trader CLI는 신중한 오랑우탄의 철학을 터미널로 옮겨온 도구입니다. 복잡한 수식보다는 명확한 규칙을, 수익보다는 생존을 우선시하는 당신을 위한 강력한 커맨드 라인 인터페이스입니다.

🦧 Ukkie CLI Introduction

Ukkie Trader CLI is a tool that brings the philosophy of a prudent orangutan to your terminal. It's a powerful command-line interface for those who prioritize clear rules over complex formulas and survival over profit.

📥 설치 방법

Python 3.10 이상의 환경에서 다음 명령어를 통해 설치할 수 있습니다.

git clone https://github.com/sjlee/ukkie-trader.git
cd ukkie-trader
pip install -e .

설치가 완료되면 터미널에서 ukkie 명령어를 사용할 수 있습니다.

📥 Installation

You can install it in a Python 3.10+ environment using the following commands.

git clone https://github.com/sjlee/ukkie-trader.git
cd ukkie-trader
pip install -e .

Once installed, you can use the ukkie command in your terminal.

🚀 빠른 시작

먼저 우끼의 철학을 확인해보세요.

ukkie zen

이제 당신만의 전략을 제안하고 검증의 숲을 통과시켜보세요.

🚀 Quick Start

First, check out Ukkie's philosophy.

ukkie zen

Now, propose your own strategy and pass it through the validation gauntlet.

ukkie zen

우끼의 트레이딩 원칙과 철학을 출력합니다. 마음이 흔들릴 때마다 읽어보세요.

ukkie zen

Outputs Ukkie's trading principles and philosophy. Read it whenever you feel wavered.

ukkie propose

새로운 전략 아이디어를 시스템에 등록합니다. 아이디어는 동결(Freeze)되어 이후 검증 과정에서 변조되지 않습니다.

ukkie propose "Breakout" "strat_v0.1.0.py"

ukkie propose

Registers a new strategy idea into the system. The idea is frozen to prevent tampering during the validation process.

ukkie propose "Breakout" "strat_v0.1.0.py"

ukkie validate

등록된 전략을 10단계 에이전트 파이프라인(Data QA, Backtest, Risk Stress 등)으로 검증합니다.

ukkie validate STRAT-ID

ukkie validate

Validates the registered strategy through a 10-agent pipeline (Data QA, Backtest, Risk Stress, etc.).

ukkie validate STRAT-ID

ukkie list

현재까지 등록된 전략들의 상태와 검증 결과를 한눈에 확인합니다.

ukkie list

View the status and validation results of all registered strategies at a glance.
